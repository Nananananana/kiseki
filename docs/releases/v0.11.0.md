# KISEKI v0.11.0

Where the model is, and what the owner writes. v0.10 made room for a
second kind of evidence; v0.11 puts two into the room -- notes and web
pages -- and both arrive through a producer that reads the text and
does not pass it on. The version's other half is the boundary that
makes such a producer meaningful at all: a classifier that discards
what it read is only as private as the machine it ran on, so where the
model is became a setting, with the strictest default and a report
computed from it.

## Highlights

- **A trust boundary, not a localhost check** (ADR-0073). The model
  may be on another machine. `same_host` is the default, a host the
  owner names is admitted as `private_network`, `anywhere` has to be
  asked for, and a refusal says what would have left. The table of
  cases is implemented three times -- core, notes producer, web
  producer -- on purpose, because a shared implementation would make
  the producers depend on the core they are meant to stand outside of.
  A conformance suite now holds the 31 cases so the three copies stay
  one rule.
- **Privacy is a report, not a promise** (ADR-0074). `kiseki privacy`
  used to assert that nothing leaves the machine, which had stopped
  being true the day captioning was written. It now computes what
  leaves from the settings in force, and every claim it prints carries
  the name of the test that keeps it true.
- **Notes: what the owner writes** (ADR-0075 to ADR-0080). A folder of
  `.md` and `.txt` files, read by `kiseki-notes`, a distribution
  outside the core. It classifies locally and keeps the category and
  the labels; the text is discarded, and so is the file name, because
  `2026-resignation.md` says as much as its contents. What reaches the
  core is `NoteRecord v1`: an owner, a producer, a day, a reference, a
  category, some labels. Seven categories carry no labels at all --
  health, money, people, credential, shopping, news, private -- and a
  document that sends labels for one is refused rather than trimmed.
- **Web pages, by the same shape** (ADR-0084, ADR-0085). `kiseki-web`
  reads a browser history without opening a page: it copies the
  database, classifies from the address and the title alone, and never
  fetches. A producer that fetched would announce the owner's history
  to every site in it. `WebRecord v1` has nowhere to put an address, a
  title, a host or a time of day.
- **A dry run before anything is recorded.** Both producers show what
  they would write and write only when told a second time. A producer
  that throws away the text is a producer whose work cannot be checked
  afterwards, so the check has to happen before.
- **A reference is a salted hash of a path** (ADR-0084). The core knows
  that two readings came from the same note or the same page, and
  cannot know which. The salt lives with the producer, which is also
  where the mapping lives. Changing the root you name changes every
  reference (ADR-0086), so a document that shares nothing with what is
  already held says so -- that is either a new source or the same one
  re-identified, and the second doubles every trail while looking like
  the first.
- **The export answers to a contract of its own** (ADR-0081).
  `kiseki-interest-export` v1 has a schema, a version and a name it
  carries in the document, and `kiseki-conformance` now validates two
  contracts rather than one. A producer in another language runs the
  command line; a producer in Python subclasses the suite.
- **Four states before an answer** (ADR-0082). A model that timed out
  is not a model that is not there, and a malformed host is neither.
  Each says which it was and names `KISEKI_MODEL_HOST`.
- **One name, many places** (ADR-0072, ADR-0083). `kiseki places` says
  how many places a single name is covering, and how far apart the
  furthest two of them are.

## What the data said

Very little, and that is the notable thing about this release.

The standing rule is that every version reserves its last issue for
what the previous version's data says. v0.10's reserved issue produced
ten changes in an afternoon and **two of them were defects no test had
caught**: `kiseki profile` was keeping a snapshot every time it printed
one, so every derivation above it was reading a record of how often
somebody typed a command (ADR-0070); and `kiseki privacy` was
asserting that no network call exists, which had stopped being true
years of commits earlier (ADR-0074). Both were found by a person
reading output. Neither was findable by a machine, because both were
behaviours somebody had written on purpose.

**v0.11 closes without that check.** Nobody read v0.11's own data.
Five questions stay open (#309):

- Do the categories divide the owner's notes the way the owner would,
  or the way a classifier finds easy?
- Does the leak rate (ADR-0077) hold outside its fixtures?
- Does a note-derived interest read as an interest, or as a word that
  happened to be typed often (ADR-0080)?
- What does the profile say now that it could not say from
  photographs, and is it true?
- The web producer classifies from an address and a title, which is
  thinner evidence than a note's text. Nobody has looked at what that
  produces.

That is a decision the owner is entitled to make. It is recorded here
as a decision and not as a completion, so that the next version knows
what it inherited.

What the data *did* say, in the one place it was asked: four merged
pull requests delivered nothing, because a stacked branch squashed
into its base loses the base's commits while GitHub reports MERGED.
539 lines were missing from `main` and every dashboard said they were
there. The checkpoint in `AGENTS.md` now reads the repository -- `git
diff --stat origin/main <head sha>` -- rather than the badge.

## Upgrading

- **Schema 9.** A v0.10 database migrates on connect, through 7 (note
  readings), 8, and 9 (page readings). The new tables are empty and
  nothing else changes.
- **Two new distributions**, neither required: `kiseki-notes` and
  `kiseki-web`. `kiseki-core` still declares no runtime dependency,
  and that is now checked against the `Requires-Dist` of a built
  wheel rather than asserted.
- **New commands**: `kiseki notes`, `kiseki web`, `kiseki llm`. New
  contracts: `docs/note-record.md`, `docs/web-record.md`.
- **`KISEKI_MODEL_HOST`, `KISEKI_MODEL_BOUNDARY`, `KISEKI_MODEL_TRUSTED_HOSTS`.** Absent, the boundary is
  `same_host` and a model on this machine works as before.
- No behaviour changes for a library of photographs alone.

## Deferred, on purpose

- **The naming of a place** stays as it is. `kiseki places` folds
  sixteen places into one town and says so; the premise that a smaller
  radius would fold fewer turned out to be wrong -- the gazetteer
  already returns the closest entry, so a smaller radius names fewer
  places rather than folding fewer.
- **A page becomes an interest** (#350) waits on a real corpus being
  read, which is not the same as waiting on #309.
- **234 Python files are not type-checked** (#355), two of them not
  tests.
