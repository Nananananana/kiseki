# KISEKI v0.8.0

Recommend with evidence. v0.8 is the version that had to be argued
with: a synthetic library and a real one took turns showing that the
design was wrong, five times, and each answer is in here.

## Highlights

- **A demo anyone can run.** `kiseki demo` builds a synthetic library
  in a sandbox and shows every deterministic derivation against it,
  then sweeps up. It calls no model and reads no configuration -- a
  demo that quietly opened the owner's real library would be worse than
  no demo, and an earlier one did exactly that. It found five design
  faults in its first week.
- **A day trip is a distance you have already travelled** (ADR-0055).
  `kiseki suggest` reads how far the owner's own outings go, takes the
  share that describes four in five of them, and offers the quiet
  places inside that reach -- visited once or twice, and not for half a
  year. Distance is measured from whichever regular place is nearest,
  because a life has more than one place it returns to. A base needs
  its visits spread over a month, so three nights in one town on
  holiday never becomes somewhere to set out from.
- **A provider may annotate, never invent** (ADR-0056). The external
  boundary is shaped so the dangerous thing is impossible rather than
  discouraged: an annotator receives suggestions and returns notes,
  with no return path by which it could add, reorder or remove one. No
  adapter ships -- the boundary exists first.
- **Timelines may be laid beside each other, never blamed**
  (ADR-0058). `kiseki drift` counts photographs, outings and screen
  readings by month and says which pairs moved together, which moved
  apart, and where each stands against its own past. The caution
  travels in the comparison's own field so a caller cannot drop it, and
  there is no word for "because" in this vocabulary. Each verdict is
  printed with the number behind it.
- **A narration is checked against the facts it was given**
  (ADR-0057). `kiseki tell` prints the story as the model wrote it and
  the doubts beneath it. It caught a real one -- the facts said 82 per
  cent of places were never returned to, and the story said 18 per cent
  were revisited.
- **The stoplist grows by its test**, and records the words it
  declined: python, vscode, ikea and yolo are what this owner actually
  works with.

## What the data said

- Day trips, on a real library: Kyoto 35 km, Kamigyo-ku 45 km,
  Nara-shi 29 km -- each two years since the last visit.
- Photographs and outings move together only weakly (+0.34), and
  outings and screens not at all (-0.01), over twenty-six months. The
  threshold was left where it was, because the numbers gave no reason
  to move it.
- A screen reading must be counted by the day the screenshot was taken,
  not the day the model read it. The first version measured this
  library instead of the person using it.

- New commands: `demo`, `drift`; `suggest` gains day trips.
