# KISEKI v0.7.0

Live with it. v0.7 is the version real data wrote: every feature in it
exists because running the library on a growing library of photographs
showed something wrong, and each fix came with the tool that would have
caught it.

## Highlights

- **Readings remember the prompt that made them** (ADR-0051). Schema 5
  adds a prompt version to every reading table, and `kiseki reread`
  reports, per stage, how many readings predate the current prompt;
  `--stage X --apply` clears exactly those, and the resumable commands
  make them again. Rows written earlier keep NULL, which says the
  version was not recorded rather than that it was empty.
- **A missing thumbnail is not the model's word** (ADR-0052). Real
  data: 163 readings had been refused because a batch of reduced
  copies sat under a different directory. ADR-0015 keeps refusals so a
  rerun never asks twice -- but that rule was written for the model's
  answer, not the environment's absence. `kiseki retry` reports the
  recoverable refusals and takes them back on request; the model's own
  refusals are never touched. All 163 came back.
- **The doctor counts missing reduced copies.** The check that would
  have caught the above before it cost anything.
- **One `kiseki refresh`.** The weekly routine in the order the
  pipeline needs, finishing with the doctor. Every stage is the command
  you would have typed, with the same defaults, and every stage is
  resumable. Ingest is deliberately absent: taking in new records is
  its own act.
- **A label about the record is not a label about the world**
  (ADR-0053). The profile had grown to 794 interests whose strongest
  two were "date" and "flight" at 1.00. A closed stoplist with a
  membership test -- the form of a record, an act of recording, or an
  abstraction with no thing behind it -- leaves those out at
  derivation, never at storage, so no model runs again. Theme names
  face the same test, and a theme absorbs the label that shares its
  name.
- **A cadence is a habit, not a trip.** `kiseki suggest` had offered
  "go back to Seoul, every ~2 days, 149 days since": three days in a
  row on a holiday, read as a rhythm. A cadence now needs visits
  spanning at least a month.
- **The findings reach the view.** The self-contained page gains what
  the last two versions learned to derive: worth a look, what the
  readings found, what changed. Still no script, no CDN, no network.
- **An answer is checked past its schema** (ADR-0054). Three defects
  reported deterministically: the answer cites nothing, cites a fact
  that does not exist, or names a year the evidence never saw. The
  answer is never rewritten. On its first real run the check reported a
  defect that was its own mistake -- a grouped citation, "[F1, F5]" --
  and the fix came with the rule: a check that cries wolf is worse than
  no check.

## Decided by measurement

The incremental build is held behind a trigger instead of written. At
4,956 photographs a full `kiseki build` takes 0.3 seconds, `profile`
1.2, `index` 0.5; ten times the library is three seconds. It gets
written when a full build passes ten seconds, or a weekly refresh
passes a minute outside the model stages -- and an incremental result
must equal the full rebuild, proven by a test.

## Upgrading

- Schema 5: a v0.6 database migrates on connect, additively.
- New commands: `reread`, `retry`, `refresh`.
- After upgrading, `kiseki doctor` is worth one run: it now names
  missing reduced copies and recoverable refusals.
